# 入口網站操作說明

## 語言切換

登入前與登入後側欄都可選擇「中文」或「English」。登入後的選擇會儲存至個人帳號，之後登入會沿用該語系；日期、相對時間、介面訊息與 API 錯誤也會一起切換。

使用者新增或修改網站標題、工作區、討論狀態、討論或回覆後，系統先保留原文，再於背景建立另一語系版本。翻譯尚未完成時會暫時顯示原文與「翻譯中」；最終失敗則顯示「翻譯失敗」，原文仍可正常閱讀與編輯。舊資料維持原樣，不會批次翻譯。

## 登入後首頁

登入後會直接進入「工作首頁」，中央顯示使用者有權限查看的所有工作區最新討論，右側顯示討論狀態統計。

- 使用工作區選單可只查看單一工作區。
- 點選「開啟討論」會進入全部討論頁並自動套用工作區。
- Guest 只會看到已受邀的工作區；未加入任何工作區時無法新增討論。

## 新增討論

1. 點選左側或頁面右上角的「新增討論」。
2. 選擇工作區與狀態。
3. 輸入標題及內容後建立。

從左側特定工作區進入後再新增討論，系統會自動帶入該工作區。

## 全部討論

- 可查看全部有權限的工作區，或使用工作區選單縮小範圍。
- 支援搜尋標題、內容及回覆。
- 可加入個人書籤、回覆及上傳附件。
- 每筆討論與回覆都可按笑臉加號開啟完整 Emoji 選擇器；點選既有 Reaction 可加入或取消，停留或鍵盤聚焦可查看標示者姓名。
- 討論作者或 Admin 可修改標題、內容與狀態。
- Admin 可置頂或封存討論。

正式 Firebase 環境會即時顯示其他使用者的 Reaction；本機 development 模式中，其他瀏覽器需重新載入資料。Reaction 不會改變未讀狀態。

## 工作區

所有角色都可查看有權限的工作區。Admin 可建立頂層工作區或在頂層下建立子工作區；子工作區不可再建立下一層。子工作區可採繼承父層成員或限制為直接成員。Admin 另可封存工作區並管理成員及角色。

## 管理後台

只有 Admin 會看到「管理後台」，可管理：

- 使用者顯示名稱、角色與啟用狀態。
- 討論狀態的新增、改名、排序、啟用與停用。
- 前往 Space 管理區建立、封存 Space 及調整成員。
