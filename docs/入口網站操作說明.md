# 入口網站操作說明

## 登入後首頁

登入後會直接進入「工作首頁」，中央顯示使用者有權限查看的所有 Space 最新討論，右側顯示公司資訊及討論狀態統計。

- 使用 Space 選單可只查看單一 Space。
- 點選「開啟討論」會進入全部討論頁並自動套用 Space。
- Guest 只會看到已受邀的 Project；未加入任何 Space 時無法新增討論。

## 新增討論

1. 點選左側或頁面右上角的「新增討論」。
2. 選擇 Space 與狀態。
3. 輸入標題及內容後建立。

從左側特定 Space 進入後再新增討論，系統會自動帶入該 Space。

## 全部討論

- 可查看全部有權限的 Space，或使用 Space 選單縮小範圍。
- 支援搜尋標題、內容及回覆。
- 可加入個人書籤、回覆及上傳附件。
- 討論作者或 Admin 可修改標題、內容與狀態。
- Admin 可置頂或封存討論。

## Space

所有角色都可查看有權限的 Space。Admin 另可建立、封存 Space，並管理成員及 Space 角色。

## 管理後台

只有 Admin 會看到「管理後台」，可管理：

- 使用者顯示名稱、角色與啟用狀態。
- 討論狀態的新增、改名、排序、啟用與停用。
- 前往 Space 管理區建立、封存 Space 及調整成員。
